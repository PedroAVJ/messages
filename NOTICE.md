# Technical notice

The plugin independently implements a minimal plain-text decoder for the `NSAttributedString` typedstream representation observed in modern macOS Messages databases. The implementation was informed by public documentation from the MIT-licensed Madrid project and the MIT-licensed `imessage-parser` project; no source code from either project is included.
